## Decisions

Add a skill-only package that retrospects CI runs for this repository: run counts, failure families by root cause, wall-clock versus queue times, re-runs, cache usage, and required check lanes. End in at most five ranked fixes. Do not compose it into AGENTS.md. Always-on compose stays over the 16 KiB house target; this procedure is on demand.

Name the package and skill ci-review. Do not name it actions-review or ci-audit. The review reports findings and records recommendations. It implements a recommendation only when requested. It does not edit pipelines without approval. It is not an umbrella for workflow-file security review; that stays with change-review and engineering-audit security mode.

Stay on this project. Window is since the last review of this kind, else the last 30 days. State which pipelines and runs were actually readable and any gaps. Prefer the host CI CLI or API (for example `gh` on GitHub). Account and auth stay in the consumer.

One failed run is a hypothesis. Confirm recurrence from run evidence. Separate queue wait from job duration before calling CI slow. Rank only the strongest five recommendations.

Durable record goes under docs/reviews per docs-conventions, one note per review episode. Link the previous review used to set the time window. Do not mark the review complete when evidence collection failed. Keep secrets out. Writing that record does not change pipelines.

Route one failing run or pull request check to that run's log. Route a pipeline file security pass to change-review with engineering-audit security mode. Route agent session retrospectives to session-review.

Later pass, 2026-10-07: review episodes move from docs/issues to docs/reviews. See docs/issues/20261007190624_docs-reviews-tree.md. Package version 1.1.0.
