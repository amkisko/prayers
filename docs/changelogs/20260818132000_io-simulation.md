# IO simulation fragment

## Participants

## Decisions

If a product depends on live IO from an external virtual or physical service, the team ships a simulation of that plant plus a control UI. The product keeps its production adapter. A person sets the parameters that produce the IO while using the product.

This is an instructor station for the plant, not a contract-test double. Skip the workbench when there is no plant, or when a vendor station already covers the parameters.

House source is io-simulation 1.0.0.
