# amkisko/security

Credential, secret, tracking, and ownership hygiene for agent-facing guidance in AGENTS.md. Skill files, prompt templates, and MCP environment settings follow the same no-live-secret rule as config files. Session notice when a live secret or confidential trace hits inference is this package; signed public comments are `amkisko/writing-prose`.

Distinct from `amkisko/community-security`, which supplies the repository root SECURITY.md file.
