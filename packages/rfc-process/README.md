# amkisko/rfc-process

Language-neutral RFC numbering, template, types, and statuses used across amkisko libraries.

Exports:

- `rfc-process` — AGENTS fragment: when to write an RFC, how to claim an id, when to run the skill
- `rfc-process` skill — claim, copy template, types, statuses, length, isolation default, and the shared `0000` template

Project bands, extra product tests, and isolation-on are declared in that repository's `rfcs/README.md`. This package does not name project URLs or repository-specific paths beyond `rfcs/`.
