# amkisko/preferred-stack

Language selection by nearest authority and proximity, UX principles, and visual-assessment communication shared across amkisko repositories.

Exports:

- `preferred-stack` fragment - native-first stop-gates, house language shortcuts, and person-facing surface rules
- `preferred-stack` skill - selection procedure and proximity bands for greenfield and polyglot boundaries

Compose the fragment in products that share these defaults. Tree the skill beside it so agents can open the procedure without loading the full band reference into always-on context.
