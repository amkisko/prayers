# amkisko/delivery-budgets

Fragment for continuous delivery budgets: named artifact size ceilings, sibling build-timing signals, recipient-matched size metrics, and when/where identity on every sample.

Compose into `AGENTS.md` for every product that ships a byte-bearing artifact. Omit only for trees that never become shipped bytes, and state that reason.

Generic guidance only. Budget numbers, registry hosts, and workflow paths stay in the consumer repository.

Related: `amkisko/engineering-audit` (resource and budget audit mode), `amkisko/ci-review`, `amkisko/publish-checks`.
