# amkisko/engineering-audit

Language- and framework-agnostic pipeline engineering audit. Boundary and control when the system talks to external services, devices, operators, or physical actuators. Place-after-refusal when the product has a place the person can return to. Resource, budget, and trace-and-identification for every executable tree. Optional modes for product surface, privacy, performance, observability, security review, contracts, learned systems, and lineage; skip any mode that does not apply. Security companions cover HTTP identity, client surface, and native interface when those surfaces exist.

Stay on concepts. Tool and framework names belong in the consumer repository, not in this skill.
