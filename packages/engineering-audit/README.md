# amkisko/engineering-audit

Language- and framework-agnostic pipeline engineering audit. Boundary and control when the system talks to external services, devices, operators, or physical actuators. Place-after-refusal when the product has a place the person can return to. Resource, budget, and trace-and-identification for every executable tree. Optional modes for product surface, privacy, performance, observability, security review, contracts, and learned systems; skip any mode that does not apply.

Stay on concepts. Tool and framework names belong in the consumer repository, not in this skill.
